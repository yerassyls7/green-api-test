# GREEN-API Test Assignment

Test assignment for GREEN-API Support Specialist position.

## Project

A web page for testing GREEN-API WhatsApp API methods.

Implemented methods:

- getSettings
- getStateInstance
- sendMessage
- sendFileByUrl

## Technologies

- HTML
- CSS
- JavaScript
- GREEN-API REST API

## Features

The page allows the user to:

- enter `idInstance` and `ApiTokenInstance`
- check instance settings
- check WhatsApp instance state
- send a WhatsApp text message
- send a file by URL
- view API responses

## Published page

The working page is published using GitHub Pages.
